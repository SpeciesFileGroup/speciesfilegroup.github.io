Our group and collaborators produce a wide range software, from small libraries to large web-apps, everything open-source

Global Names Architecture

Indexing the world's taxon names

The Global Names Architecture is an umbrella for a wide range of software. Code is available on Github.

TaxonWorks

Describe life

TaxonWorks is a 3rd (4th?) generation workbench that has a rich history of precursors including 3i, mx, and Species Files.

TaxonPages

TaxonPages is for taxon pages

TaxonPages is an easy to use framework for building pages about the Earth's species.

Libraries, gems, modules, etc.

Multi-use utilities

Our goal is to continually move toward isolating code into small, generally useful libraries. See the GNA tools, and general utilities in the Species File Group repositories on Github.
